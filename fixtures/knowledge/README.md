# 지식 화면 예제 (개발용)

`pnpm dev`(예제 모드)가 `.sandbox/`로 복사해 쓰는 지식 예제다. 실제 Study vault, Emergence Topic Review, research-library의 모양만 흉내 낸다.

- `study/Concept-Space/<분류>/…/<제목>.md` — Obsidian Study (읽기만)
- `topic-reviews/` — Emergence `site/content/reviews/topic/` (읽기만)
- `library/concepts`, `library/papers` — 예제 라이브러리에 더하는 개념노트·문헌노트
