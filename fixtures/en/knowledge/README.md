# Knowledge screen sample (for development)

Knowledge sample that `pnpm dev` (sample mode) copies into `.sandbox/`. It only imitates the shape of a real Obsidian vault, a topic-review folder and a shared library (research-library).

- `study/Concept-Space/<category>/…/<title>.md` — Obsidian vault (read-only)
- `topic-reviews/` — topic-review folder (read-only)
- `library/concepts`, `library/papers` — concept notes and literature notes added to the sample library
